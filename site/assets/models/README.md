# Lander display assets

These display assets are loaded locally by both the probe gallery and the flight animation.

- `lunar-lander.glb`: embedded glTF copyright identifies Innerscene Corp and dedicates the asset to CC0 1.0 Universal. Used as a representative display for Nova-C.
- `vikram-lander.glb`: Vikram geometry extracted from "Chandrayaan-2 in flight configuration" by tashtego, CC BY 4.0. Source model: https://sketchfab.com/3d-models/chandrayaan-2-in-flight-configuration-4d0017f2c5fb49bb9817601858106ddb . Retrieved from the credited copy at https://github.com/kvsankar/chandrayaan3/blob/master/third-party/models/cy3-small.glb . Licence: https://creativecommons.org/licenses/by/4.0/ . Modified by removing the orbiter and unused assets, retaining the lander geometry and textures. The card describes Vikram's mission history; the geometry is a Chandrayaan-2 reference rather than an exact Chandrayaan-3 reconstruction.
- `apollo-lm.glb`: NASA/Michael D. Carbajal, from the official [Apollo Lunar Module resource](https://science.nasa.gov/3d-resources/apollo-lunar-module/). Reimported from the page's original [GLB download](https://assets.science.nasa.gov/content/dam/science/cds/3d/resources/model/apollo-lunar-module/Apollo%20Lunar%20Module.glb) on 2026-11-15. Original file SHA-256: `379101dfcee399267addf771709107c35e826b0b9e5233272f123e4c8a585c4e`. The downloaded original matches the previously supplied file. Geometry, UVs, embedded textures and markings are unchanged; metallic and roughness factors were adjusted for the requested reflective display finish.
- `artemis-lite.glb`: simplified copy (about 55,000 triangles, 4 MB, flat-shaded) of the supplied Artemis concept OBJ, which the local demo identifies as a CGTrader download. The original 65.8 MB OBJ is not in the repository. Redistribution terms of the original are unverified. Silver, dark metal and gold materials are illustrative finishes assigned using the original material names, which are preserved. The reflective finish is saved in the GLB so the gallery and flight share the same materials.

`artemis-lite.glb` still requires source and licence verification before public distribution; its inclusion does not establish permission to publish.

Three.js loaders, utilities and Draco decoder files are vendored from the Three.js r170 distribution, alongside its existing MIT licence. Model loading has no external runtime dependency.
