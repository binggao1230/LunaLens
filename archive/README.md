# Archive

Material kept for history. Nothing here is current: do not follow it, link to it, or add to it.

## team/ (archived 2026-11-14)

One folder per person, each with a `README.md` briefing and a `TODO.md` progress list. The split stopped matching
how the work was actually going, and the lists were kept by hand while the work itself moved to pull requests, so
the folders were retired two days before submission.

Progress is tracked in pull requests and in the root `TODO.md`.

`team/chenlin/` held a 35 MB snapshot of a standalone website in twelve zip parts. The parts now live on the
`lunalens-snapshot-2026-11-14` release and are out of git; `WEBSITE.md` says how to fetch them.

## doc/ (archived 2026-11-14)

`PLAN.md`, `PRODUCT.md`, `WORKPLAN.md` and `PLAN_3D.md`: the planning documents written before and during the first
day. They describe a `backend/` + `web/` architecture and a 3D programme that the team did not build; the product
became the static `site/`. They are kept because code comments and checks cite sections of them (the Horizons
fixture, the deployment notes). What to do next is in the root `TODO.md`; the rules are in `AGENTS.md`.
